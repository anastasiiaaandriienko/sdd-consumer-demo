# sdd-consumer-demo

A tiny Node.js notes module used to test Claude Code plugins from
`dev-digest-ai-marketplace`.

- Code: `src/`, tests: `test/` (`node:test`), no dependencies.
- Check command: `npm test`.
- SDD artifacts: `specs/<slug>/`.
- Protected paths: `package.json` dependency sections, `.claude/**`, `CLAUDE.md`.
